# Leonardo's Four-Phase Deep-Study Method

Operationalizes Leonardo's four-phase method for turning any structured material into deeply internalized understanding — not a transcription of the source, but a reconstruction the learner owns. It works because it forces the learner to *rebuild* the knowledge in their own mind rather than merely recognize it on the page. Sometimes called "the wooden sphere method."

## Core metaphor

Organized knowledge — a book, paper, lecture, course — is an assembled wooden sphere: whole, internally logical, sitting in front of you. You can describe it, even praise it — but you don't own it. To own it you must **disassemble it, hold the pieces, see how each fits, and reassemble it yourself** — repeatedly, with less reference to the original each time. Passive reading leaves the sphere assembled; that's why it doesn't produce mastery.

## The four phases

Applied in order; Phase 3 iterated multiple times. Each has a distinct cognitive function — skipping or reordering produces shallow learning that fades in weeks.

### Phase 1 — Desconstrução
**Goal:** expose the brain to the material and let it become *productively confused*. **Do:** pick a perennial source (avoid ephemeral ones you can't return to); read carefully, annotate freely, write questions in the margins — engaged reading, not the perfect note. Confusion here is fuel, not failure. **Don't:** memorize, summarize, or skim.

### Phase 2 — Captura de ideias
**Goal:** catch the insights the brain produces while it keeps processing in the background. **Do:** after Phase 1, live your life — walk, cook, attend class — and capture connections/questions/analogies the moment they surface (notebook, voice memo, a line in a vault). A live class belongs here, not Phase 1. **Why:** these fleeting ideas are what make the final notes *yours*; uncaptured, they're gone in a minute. *Variation:* for holistic or affective insight, writing can collapse the thought — use voice or dialogue instead.

### Phase 3 — Experimentação
**Goal:** rebuild the sphere yourself, find the gaps, force the connections. **Do:** on a blank page, without the source, rewrite everything you know in your own words as if teaching it. You'll hit gaps where reasoning breaks — **those gaps are the point.** Then do something radical: discard it and start over, several times. If the material has problems, solve a substantial number (they test both *knowing* and *using* the theory — different skills). **Why:** writing from memory reconstructs the whole structure instead of recognizing it; this is where the higher-order thinking happens.

### Phase 4 — Reconstrução
**Goal:** produce the final notes — the artifact carrying *your* perspective. **Do:** now internalized, write the definitive notes in your own voice and order, with the connections (Phase 2) and filled gaps (Phase 3), linked to what you already know. They'll contain things not in the source — that's the point. **The paradox:** by now you barely need the notes; learning already happened in 1–3. Phase 4 records it to revisit or teach.

## Running a study project

1. **Identify the material.** Confirm format and scope. If the source is ephemeral, use it as a Phase-2 trigger and find a perennial source for Phase 1.
2. **Plan the phases** against available time: Phase 1 = one or a few sessions; Phase 2 = background over days; Phase 3 = multiple iterated sessions; Phase 4 = one focused session.
3. **Support each phase distinctly.** P1: reading aids, terminology, tracking coverage — *don't summarize for them* (the confusion is productive). P2: receive their captures, organize by theme without flattening the fragments, ask Socratic questions. P3: be the imaginary student — listen to their reconstruction, point out gaps, **refuse to feed the answer**, suggest problems. P4: help with structure, linking, naming — the conceptual content is theirs.
4. **Mark provenance** in the final notes: what's from the source vs. the learner's own connection.

## Adaptation by content type

- **Books / papers:** the canonical case — apply as described.
- **Video lectures / courses:** the recording is the Phase-1 source; use problem sets in Phase 3.
- **Docs / codebases:** Phase 3 = write the code from scratch without copying; Phase 4 = architecture notes in your own words.
- **Podcasts / interviews:** transcript as source; Phase-2 captures matter more than the linear content.
- **Practical skills:** Phase 3 becomes deliberate practice; physical embodiment replaces some cognitive reconstruction.

## Output

A **final note** in the learner's vault: a clear title; their reconstruction of the core ideas in their own voice; the connections they discovered (linked); the gaps they filled ("I missed X; the path to seeing it was Y"); anchor questions for revisiting; provenance markers. If the note reads like the source's table of contents, Phase 3 was skipped.

## When NOT to use

A quick answer or summary; consuming for entertainment; a single short article not worth multi-session investment; a deadline that prevents iterating Phase 3 (a simpler protocol is more honest then); or a study system that's already working — don't impose this on top.

## Common failure modes

- **Stopping at Phase 1** (reading mistaken for learning) → force Phase 3: close the book, write from memory.
- **Skipping Phase 2** → competent but generic notes; take a walk before Phase 3.
- **Too few Phase-3 iterations** → set a target ("rebuild three times").
- **Phase 4 = transcription** → nothing in the note that wasn't in the source means the method was bypassed.

## Related methods

Shares territory with Justin Sung's encoding cycles and the Zettelkasten writing-to-think tradition; what's distinctive is the four-phase macro-structure, the "amasse o papel" radical iteration in Phase 3, and the Phase-4 paradox. Complementary, not rival.
