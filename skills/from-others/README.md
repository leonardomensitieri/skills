# from-others

Skills reused from other authors, kept **faithful** to upstream (with their license) so we can diff against the source and credit by folder. We depend on these by **invoking** them (`/grilling`, `/domain-modeling`, …) — never by cross-linking their files.

One folder per author:

- **[matt-pocock/](./matt-pocock/)** — from [`mattpocock/skills`](https://github.com/mattpocock/skills) (MIT): `grilling`, `grill-me`, `grill-with-docs`, `domain-modeling`, `handoff`.
- **[anthropic/](./anthropic/)** — Anthropic's built-in skills (Apache-2.0): `skill-creator`. A faithful snapshot of the version shipped with Claude Code (the forge invokes `/skill-creator`); may lag upstream.
