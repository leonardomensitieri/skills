# Skills

Each folder with a `SKILL.md` is a skill, organized into buckets by maturity and origin. Only stable buckets appear in the top-level README and the plugin.

- **[in-progress](./in-progress/README.md)** — Drafts still in development. Today: `forge` (forge a skill from an expert's method), `leonardo-method` (four-phase deep study), our one-at-a-time `grilling`, and `antithesis-red-teaming`.
- **[from-others](./from-others/README.md)** — Skills reused from other authors, kept **faithful** (with their license) so we can diff upstream and credit by folder. Dependencies are expressed by **invoking** these skills (`/grilling`, `/domain-modeling`, …), never by cross-linking their files. Today: `matt-pocock/` (grilling, grill-me, grill-with-docs, domain-modeling, handoff) and `anthropic/` (skill-creator).
